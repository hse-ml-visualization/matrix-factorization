# Matrix Lab

Интерактивная лаборатория для изучения матричных разложений. Курсовой проект

## О проекте

Matrix Lab - это веб-приложение для визуального и математического исследования матричных разложений. Создано как инструмент для изучения линейной алгебры: позволяет экспериментировать с матрицами, наблюдать работу алгоритмов в динамике и понимать математическую основу каждого разложения.

Проект сочетает интерактивную визуализацию и строгую математику:
- Визуализация матриц через тепловые карты
- Итеративные алгоритмы с отображением сходимости
- Пошаговые расчёты для 2×2 матриц как в учебнике

### Основные разделы

| Раздел | Что делает |
|----------|-------------|
| **Матрица A** | Редактор матриц и быстрое сравнение алгоритмов. Задайте размер, диапазон значений, seed. Сразу видно оригинал, восстановление и ошибку для каждого алгоритма |
| **Разложения** | Детальный разбор каждого разложения по шагам. Визуализация матриц U, Σ, V и других компонент. Для итеративных методов (NMF, ALS) — график сходимости и слайдер по итерациям |
| **Эксперименты** | Исследования: центр vs края матрицы, как возмущение в одной ячейке распространяется на восстановление |
| **Теория** | Математическая основа каждого разложения с примерами для 2×2 матриц |
| **Код** | Краткие заметки о реализации и структура проекта |
| **Калькулятор** | Пошаговый расчет разложений для 2×2 матриц (через бэкенд) |

### Поддерживаемые разложения

- **SVD** (Singular Value Decomposition) - сингулярное разложение
- **PCA** (Principal Component Analysis) - метод главных компонент
- **NMF** (Non-negative Matrix Factorization) - неотрицательное разложение
- **CUR** — разложение по реальным строкам и столбцам матрицы
- **ALS** (Alternating Least Squares) - попеременные наименьшие квадраты

## Как запустить локально

### Вариант 1: Только фронтенд (быстрый запуск)

Для основного функционала (все вкладки кроме «Калькулятор») достаточно статического сервера:

```bash
cd matrix-lab
python3 -m http.server 8080
```

Откройте в браузере: http://localhost:8080

### Вариант 2: С бэкендом (полный функционал)

Для пошагового калькулятора нужен Flask:

```bash
# установите зависимости
pip3 install flask flask-cors numpy

# запустите бэкенд
python3 server.py
```

Бэкенд запустится на http://localhost:5000

Теперь запустите фронтенд (в другом терминале):

```bash
python3 -m http.server 8080
```

Вкладка «Калькулятор» будет работать и показывать пошаговые расчёты.

Запуск на удалённом сервере: https://matrix-lab.ru.tuna.am
