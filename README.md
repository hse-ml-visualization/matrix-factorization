# Matrix Lab

Интерактивная лаборатория для изучения матричных разложений. Курсовой проект

## О проекте

Matrix Lab - веб-приложение для визуального и математического исследования матричных разложений. Создано как инструмент для изучения линейной алгебры: позволяет экспериментировать с матрицами, наблюдать работу алгоритмов в динамике и понимать математическую основу каждого разложения.

Проект сочетает интерактивную визуализацию и строгую математику:
- Визуализация матриц через тепловые карты (viridis / diverging)
- Итеративные алгоритмы с отображением сходимости
- Пошаговые расчёты для 2x2 матриц как в учебнике

## Вкладки приложения

| Вкладка | Описание |
|---------|----------|
| **Визуализатор** | Редактор матриц (инлайн-ввод, изменение размера, колёсико для +/-0.1) + быстрые пресеты (Единичная, Нулевая, Случайная, Пример 4,3;2,1) + пошаговый пайплайн разложения с цветовыми стрелками операций (умножение, транспонирование, нормализация, собственные значения, инициализация). Для каждого алгоритма визуализируются U, Sigma, V, матрица восстановления, график сингулярных чисел, ошибка. Для итеративных методов (NMF, ALS) - интерактивный график сходимости и слайдер по итерациям |
| **Эксперименты** | Два исследования с пресетами матриц: (1) центр vs края - статистика ошибки по N случайным матрицам, гипотеза что центр восстанавливается хуже; (2) возмущение Delta в одной ячейке - радиальный распад влияния на восстановление, регулируется колёсиком мыши |
| **Теория** | Полный математический вывод каждого разложения для матрицы 2x2: характеристическое уравнение, собственные значения, собственные векторы, построение приближения |
| **Код** | Реализация каждого разложения на JavaScript (ES6) и Python с комментариями, примерами из жизни и кнопкой копирования |
| **Калькулятор** | Пошаговый расчёт через Flask-бэкенд: ввод матрицы 2-6x2-6, выбор итераций, анимированные шаги с LaTeX-формулами и тепловыми картами |

## Поддерживаемые разложения

- **SVD** (Singular Value Decomposition) - сингулярное разложение через numeric.js, усечение до ранга k
- **PCA** (Principal Component Analysis) - метод главных компонент: центрирование + SVD
- **NMF** (Non-negative Matrix Factorization) - неотрицательное разложение, мультипликативное обновление (MU), детерминированная инициализация от seed матрицы
- **CUR** - разложение по реальным строкам и столбцам: отбор топ-k по норме + псевдообратная через SVD
- **ALS** (Alternating Least Squares) - попеременные наименьшие квадраты с L2-регуляризацией, детерминированная инициализация

## Структура проекта

```
matrix-lab/
├── index.html           # Главная страница

│   ├── main.js          # Точка входа, переключение вкладок, общее состояние (seed, A, k, iters)

│   ├── decompositions.js # Реализация SVD, PCA, NMF, CUR, ALS (321 строка)
│   ├── experiments.js   # Эксперименты: центр/края, возмущение Delta (256 строк)
│   ├── theory.js        # Полный матвывод для 2x2 для каждого разложения (341 строка)
│   ├── code.js          # Код разложений на JS + Python с копированием (531 строка)
│   ├── calculator.js    # Калькулятор с анимированными шагами через бэкенд (395 строк)
│   ├── matrix.js        # Операции над матрицами (zeros, clone, random, frobNorm, dot, ...)
│   ├── heatmap.js       # Отрисовка матриц - тепловые карты viridis/diverging
│   ├── dom.js           # DOM-утилиты: аккордеон, график сходимости, слайдер, bar-чарт, decay
│   ├── palettes.js      # Цветовые схемы: viridis (последовательная), diverging (дивергентная)
│   ├── rng.js           # mulberry32 - детерминированный PRNG
│   └── styles.css       # Полная тёмная тема (1666 строк), анимации, responsive

```

## Как запустить локально

### Вариант 1: Только фронтенд (быстрый запуск)

Для основного функционала (все вкладки кроме "Калькулятор") достаточно статического сервера:

```bash
cd matrix-lab
python3 -m http.server 8080
```

Откройте в браузере: http://localhost:8080

### Вариант 2: С бэкендом (полный функционал)

Для пошагового калькулятора нужен Flask:

```bash
# установите зависимости
pip3 install flask flask-cors numpy

# запустите бэкенд
python3 server.py
```

Бэкенд запустится на http://localhost:5000

Теперь запустите фронтенд (в другом терминале):

```bash
python3 -m http.server 8080
```

Вкладка "Калькулятор" будет работать и показывать пошаговые расчёты.

Запуск на удалённом сервере: https://matrix-lab.ru.tuna.am

## Технологии

- Фронтенд: чистый JavaScript (ES6 модули)
- Визуализация: Canvas (тепловые карты через div/grid)
- Математика: numeric.js (клиент) + NumPy (сервер)
- Бэкенд: Flask + flask-cors
- Математические формулы: KaTeX
- Генератор случайных чисел: mulberry32 (детерминированный)
